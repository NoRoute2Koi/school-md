# SchoolMD

> **Версия:** 1.1.0

Быстрый и легковесный FOSS-клиент для образовательных платформ **«Моя Школа»** (МЭШ / school.mos.ru, Моя Школа МО / authedu.mosreg.ru), выполненный в дизайн-системе **Material 3 Expressive (MD3E)**.

## Возможности

* **Трехшаговый онбординг первого запуска (MD3 Expressive)**:
  * Экран приветствия с адаптивной иконкой приложения.
  * Интерактивный список регионов с подсветкой выбора и ссылками на образовательные платформы.
  * Удобная авторизация через Госуслуги, получение и валидация JWT токена в реальном времени.
* **Расписание уроков в стиле MD3 Expressive**:
  * Карточки занятий с временем звонков, номерами кабинетов и темами уроков.
  * Фирменный индикатор загрузки `ContainedLoadingIndicator` с плавным морфингом геометрических фигур внутри скругленного контейнера.
  * Интерактивная полоса дней недели с индикатором текущего дня и плавными Compose-анимациями.
  * Удобная навигация по неделям (переключение вперед/назад, кнопка быстрого возврата «Сегодня», понятные диапазоны дат, свайпы влево/вправо).
  * Динамические бейджи статусов: «Сейчас идёт» (с живым пульсирующим индикатором), «КР» (контрольные работы), «Замена», «Отменён», оценки и индикация домашних заданий.
  * Корректная обработка каникул, выходных и пустых дней с подсказками перехода к учебным неделям.
* **Оценки и дневник**:
  * Просмотр оценок по дням недели и по предметам.
  * Средневзвешенные баллы с учётом веса оценок (контрольные, ответы на уроке и т.д.).
  * Детальные BottomSheet-шторки для каждой оценки с темой, весом, датой и именем преподавателя.
* **Домашние задания**:
  * Удобная группировка по датам, фильтрация по статусу (Все / К выполнению / Выполненные) и предметам.
  * Полнотекстовый поиск по заданиям и предметам.
  * Индикатор и прогресс-бар выполнения заданий на неделю.
  * Быстрая отметка выполнения галочкой прямо из списка или в окне деталей.
* **Профиль ученика**:
  * Отображение имени, фамилии, класса и образовательного учреждения (подтягиваются из официального API по токену).
  * Установка аватара (локально) через системный Android Photo Picker без запроса лишних разрешений на всё хранилище.
  * Автоматическая генерация инициалов, счётчик оставшегося времени действия токена, проверка шлюза и инспектор JWT.
* **Material You и дизайн**:
  * Полная поддержка динамических цветов Material You (Android 12+), синхронизированных с обоями системы.
  * Адаптивная иконка приложения с динамическим Monet-перекрасом (работает всегда, даже когда тематические иконки выключены в лаунчере) и Themed Icons (Android 13+).
* **Авторизация и безопасность**:
  * Вход через системный браузер (Chrome, Firefox и др.) через Госуслуги / ЕСИА.
  * Шифрование сохранённых токенов в `EncryptedSharedPreferences` (MasterKey AES-256).
  * Безопасное подписание Release APK через локальный `keystore.properties` без хранения секретов в репозитории.
* **Легковесность и производительность**:
  * Предпочтение стандартной библиотеке Kotlin/Java (`java.time`, `java.util.Base64`, `org.json`) без избыточных тяжелых зависимостей и трекеров.
  * Кэширование расписания, оценок и заданий в памяти и локально для мгновенного отклика при открытии.

## Стек 

* **Язык**: Kotlin 2.1.0
* **UI**: Jetpack Compose (BOM 2024.10.01) + Material 3 (1.3.1)
* **Сеть**: OkHttp 4.12
* **Безопасность**: AndroidX Security Crypto (`EncryptedSharedPreferences`)
* **Дата и время**: Java 8+ `java.time` (Desugaring / minSdk 26)
* **Платформа**: Android 8.0 — Android 15 / 16 / 17 (minSdk 26, targetSdk 35, поддержка Edge-to-Edge и Predictive Back)

## Сборка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/noroute2koi/school-md.git
   cd school-md
   ```

2. Соберите Debug APK:
   ```bash
   ./gradlew assembleDebug
   ```
   Собранный файл будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.

3. Установите на подключенное Android-устройство (через ADB):
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

4. Запустите юнит-тесты:
   ```bash
   ./gradlew testDebugUnitTest
   ```
