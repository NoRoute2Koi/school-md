# Моя Школа (Android)

Современный, быстрый и легковесный FOSS-клиент для образовательных платформ **«Моя Школа»** (МЭШ / school.mos.ru, Моя Школа МО / authedu.mosreg.ru), выполненный в дизайн-системе **Material 3 Expressive (MD3E)**.

## Возможности

* 📅 **Расписание уроков в стиле MD3 Expressive**:
  * Карточки занятий с плавными экспрессивными скруглениями (26dp), временем звонков, номерами кабинетов и темами уроков.
  * Интерактивная полоса дней недели с индикатором текущего дня и плавными Compose-анимациями.
  * Удобная навигация по неделям (переключение вперед/назад, кнопка быстрого возврата «Сегодня», понятные диапазоны дат).
  * Динамические бейджи статусов: «Сейчас идёт» (с живым пульсирующим индикатором), «КР» (контрольные работы), «Замена», «Отменён», оценки и индикация домашних заданий.
  * Корректная обработка каникул, выходных и пустых дней с подсказками перехода к учебным неделям.
* 👤 **Профиль ученика**:
  * Отображение имени, фамилии, класса и образовательного учреждения (подтягиваются из официального API по токену).
  * Установка аватара через системный Android Photo Picker (`PickVisualMedia`) без запроса лишних разрешений на всё хранилище.
  * Автоматическая генерация инициалов, счётчик оставшегося времени действия токена, проверка шлюза и инспектор JWT.
* 🔐 **Безопасная авторизация**:
  * Вход через системный браузер (Chrome, Firefox и др.) через Госуслуги / ЕСИА без встроенных WebViews.
  * Шифрование сохранённых токенов в `EncryptedSharedPreferences` (MasterKey AES-256).
* ⚡ **Легковесность и производительность**:
  * Ponytail-подход: предпочтение стандартной библиотеке Kotlin/Java (`java.time`, `java.util.Base64`, `org.json`) без избыточных тяжелых зависимостей и трекеров.
  * Кэширование расписания в памяти и локально для мгновенного отклика при открытии.

## Стек технологий

* **Язык**: Kotlin 2.1.0
* **UI**: Jetpack Compose (BOM 2024.10.01) + Material 3 (1.3.1)
* **Сеть**: OkHttp 4.12
* **Безопасность**: AndroidX Security Crypto (`EncryptedSharedPreferences`)
* **Дата и время**: Java 8+ `java.time` (Desugaring / minSdk 26)

## Сборка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/<username>/school.md.git
   cd school.md
   ```

2. Соберите Debug APK:
   ```bash
   ./gradlew assembleDebug
   ```
   Собранный файл будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.

3. Установите на подключенное Android-устройство (через ADB):
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

4. Запустите юнит-тесты:
   ```bash
   ./gradlew testDebugUnitTest
   ```
