### General
- тебе разрешенно работать только в директории "school-md"
- директория .ai/ это место с твоими промптами, тебе разрешенно иногда редактировать их
- веди свой TODO.md в директории .ai/ c завершёнными/текущими/будущими задачами
- используй MCP context7

### NixOS
- ты работаешь на NixOS, учитывай это
- если нужен какой то пакет временно, то используй "nix-shell -p"
- если нужен постоянный пакет то попроси меня установить его в систему

### Git
- если данная директория не git репозиторий - инициализируй его
- используй ветку main
- не изменяй global config
- создавай коммиты для разных изменений и подписывай их на английском языке
- веди .gitignore и добавляй туда необходимые файлы/директории
- перепроверяй код на наличие личных данных
- запрещенно использовать какие либо личные данные к примеру ФИО в коде
- используй git filter-repo для удаления чего либо из истории
- тебе запрещенно самому пушить код ьез разрешения
